# turnip-a750

Mesa Turnip Vulkan driver built for Snapdragon 8 Gen 3 (Adreno 750), packaged for AdrenoTools.

**Build:** Actions → Build Turnip (Adreno 750) → Run workflow. Grab the zip from Releases.

**Install:** import the zip in your emulator's GPU driver manager (Eden/Citron, Winlator, GameNative, etc).
